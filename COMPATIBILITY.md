# Compatibility

| Component | Supported version / state |
| --- | --- |
| AstrBot | `>=4.28,<5` |
| Himeko Companion plugin | `1.0.0` release candidate |
| Python | Use the Python environment bundled with or documented by your AstrBot installation |
| Models and platforms | Selected and configured by the user in AstrBot; no provider or platform is bundled here |

When either repository changes an installation step, plugin schema, or supported AstrBot range, update this table and the corresponding README in the same reviewed release. A documentation-only edit that does not change these contracts does not require a cross-repository release.
